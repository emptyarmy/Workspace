# Example research note

Use `1-research/` to capture what you learned *before* deciding something — options you compared, links, trade-offs. It's where a decision (`2-decisions/`) gets its evidence.

**Example.** "Which language for the first example feature? Python is already set up via `uv`, reads almost like plain English, and is forgiving for beginners — so the example uses Python. The other supported languages (Node, Ruby, Java, Rust) are one `rewrite-in-language` skill away." → led to `2-decisions/EDR-001-example-decision.md`.
