# Glossar

| Begriff (DE) | Begriff (EN) | Erläuterung |
|---|---|---|
| Kernbereich (KB) | Key area | Thematischer Aspekt des Testprozesses, z. B. Teststrategie. TPI NEXT® kennt 16. |
| Reifegrad / Ebene | Maturity level | INITIAL → KONTROLLIERT → EFFIZIENT → OPTIMIEREND (TPI NEXT®). |
| Kontrollpunkt (KP) | Checkpoint | Prüfbare Aussage; alle KP einer Ebene müssen erfüllt sein, damit die Ebene erreicht ist. |
| Operative Sicht | Category / operational view | Agile TPI: Individuum (P), Team (T), Organisation (O). |
| Cluster | Cluster | Agile TPI: Gruppierung von KP zu Verbesserungsschritten A–G (Priorisierung). |
| Reifegradmatrix | Test maturity matrix | Tabellarische Darstellung aller KP, farbcodiert nach Erfüllung. |
| Netzdiagramm | Spider/Radar chart | Erfüllungsgrad je Kernbereich in Prozent. |
| Assessment / Bewertung | Assessment | Eine Befragungsrunde für ein Projekt zu einem Zeitpunkt. |
| Quelle / Autor | Source / Author | Person oder Dokument, aus dem eine Aussage/ein Kommentar stammt. |
| Kurzfristige Maßnahme | Quick win | Umsetzbar in < 1 Monat. |
| Langfristige Maßnahme | Long-term improvement | Umsetzungsdauer ≥ 1 Monat. |
| KVP | CIP | Kontinuierlicher Verbesserungsprozess. |
| Human-in-the-Loop | Human-in-the-loop | Menschliche Prüfung und Freigabe von KI-Ergebnissen. |
| LLM | LLM | Large Language Model, Sprachmodell für generative KI. |
| Mandant / Firma | Tenant / Company | Organisation mit eigenem Logo, eigener Branche und getrennten Daten. |
| Branche | Industry | Wirtschaftszweig der Firma, Grundlage des Branchen-Benchmarks. |
| Benchmark | Benchmark | Anonymisierter Vergleich mit Branche und allen Firmen (Median, Quartile). |
| Abteilungsantwort | Department answer | Antwort einer Abteilung auf einen Kontrollpunkt. |
| Konsolidierte Antwort | Consolidated answer | Vom Assessor festgelegte, für den Bericht maßgebliche Antwort. |
| Konsenslücke | Consensus gap | Kontrollpunkt, zu dem die Abteilungen unterschiedlich geantwortet haben. |
| Änderungshistorie | Change history | Unveränderbares Protokoll aller fachlichen Änderungen (wer, wann, was). |
| Einmal-Link | One-time link | Zeitlich begrenzter, nur einmal nutzbarer Link zum Setzen des Passworts. |
| Rolle | Role | Admin, Assessor, Befragter oder Leser – genau eine je Nutzer. |
