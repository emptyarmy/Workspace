## Projektstand

| Phase | Inhalt | Stand |
|---|---|---|
| 0–1 | Analyse, Planung, Klärung der offenen Fragen | abgeschlossen |
| 2 | Fragenkatalog v1.0 (19 Kernbereiche, 223 Kontrollpunkte) | Entwurf fertig, fachliche Prüfung ausstehend |
| 3 | Grundgerüst (Vue 3, Fastify, PostgreSQL, Tests) | abgeschlossen |
| 4a | Anmeldung, Einladung, Einmal-Link, Admin-Bereich der eigenen Firma | abgeschlossen |
| 4b | Firmenübergreifende Administration, Abteilungen, Branchen, E-Mail und KI je Firma, Audit-Log | abgeschlossen |
| 5 | Assessments, Fragebogen, Kommentare, Zusammenführung, Änderungshistorie, Live-Aktualisierung, Import/Export | abgeschlossen |
| 6 | Bericht und Benchmark | abgeschlossen |
| 7 | Handlungsempfehlungen (Regeln und KI) und Maßnahmenplan | abgeschlossen |
| 8 | Abschluss: CI/CD, Security-Review, Betriebsdokumentation, Abnahme | geplant |
