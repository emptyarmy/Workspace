# tests/

- `e2e/` – Playwright-Specs (Positiv- und Negativtests), Page Objects in `e2e/pages/`
- Unit-, API- und DB-Tests liegen beim jeweiligen Paket (`packages/*/test`, `apps/server/test`) und laufen mit `npm run test:unit`.

Testfall-IDs (z. B. `TC-PWD-012`) stehen im Testtitel und verweisen auf `docs/05_test/02_testfallkatalog.md`.
